# Fast Asleep (Sloom Clone)

This is a React website clone of [Sloom.co.za](https://sloom.co.za/) populated with content from [FastAsleep.co.za](https://fastasleep.co.za/).

## Project Structure
- **Framework**: Vite + React
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Fonts**: Montserrat (Google Fonts)

## Setup & Running
Since this project was generated via a script, you need to install the dependencies first.

1.  Open your terminal.
2.  Navigate to the project directory:
    ```bash
    cd "/Users/curt/Desktop/Fast Asleep React"
    ```
3.  Install dependencies:
    ```bash
    npm install
    ```
4.  Start the development server:
    ```bash
    npm run dev
    ```
5.  Open the link provided (usually `http://localhost:5173`) in your browser.

## Features
- **Design System**: Matches Sloom's Navy (#0F1E43) and Gold (#C8A157) color palette.
- **Components**:
    - Sticky Navbar with mobile menu.
    - Hero section with Fast Asleep tagline.
    - Product Grid displaying Fast Asleep mattresses.
    - Features section (Pressure Relief, Support, etc.).
    - Footer with links and copyright.
- **Responsiveness**: Fully responsive layout for mobile, tablet, and desktop.
